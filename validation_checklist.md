# Validation Checklist

## Medical Accuracy
- [ ] Verify all recommendations are evidence-based from authoritative sources
- [ ] Confirm all recommendations are actionable at individual provider level
- [ ] Check that recommendations are appropriate for Medicaid/underserved populations
- [ ] Ensure recommendations are current (within last 20 years)
- [ ] Validate that implementation guidance is specific and practical

## Citation Style
- [ ] Verify all citations follow JAMA/AMA style
- [ ] Check that all citations include author names, title, journal, year, volume, pages, and DOI when available
- [ ] Confirm all citations are from peer-reviewed or authoritative sources
- [ ] Ensure citation dates are within the last 20 years

## JSON Structure
- [ ] Validate all JSON files against schema
- [ ] Check for required fields in all recommendations
- [ ] Verify unique IDs for all recommendations
- [ ] Confirm appropriate tagging for filtering
- [ ] Test JSON files for parsing errors

## Completeness
- [ ] Verify all 22 domains are represented
- [ ] Confirm all 8 roles are represented
- [ ] Ensure at least 250 total recommendations
- [ ] Check that prenatal and postnatal domains are included
- [ ] Verify doula role is included
- [ ] Confirm all JSON files are downloadable

## Website
- [ ] Verify Waymarkcare colors and style are applied
- [ ] Check responsive design for mobile compatibility
- [ ] Ensure all links are functional
- [ ] Confirm download functionality works
- [ ] Test search functionality
